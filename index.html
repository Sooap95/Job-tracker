📁 Structure de dossier recommandée
Posez ce dossier dans votre répertoire principal de recherche d'emploi. Organisez vos documents ainsi :
Recherche_Emploi/ ├── job-tracker/ ← cet outil (index.html, style.css, app.js) ├── backup_jobs.json ← export régulier depuis l'outil │ ├── Candidatures/ │ ├── 2026-03_Entreprise_Poste/ │ │ ├── CV_NomPrenom_Entreprise.pdf │ │ ├── LM_Entreprise_Poste.pdf │ │ └── confirmation_envoi.pdf │ └── 2026-03_AutreEntreprise_AutrePoste/ │ └── ... │ ├── RAV_Rapports/ │ ├── 2026-03_preuves_recherche_emploi.pdf │ └── 2026-02_preuves_recherche_emploi.pdf │ └── Documents_Base/ ├── CV_NomPrenom_2026.pdf ├── CV_NomPrenom_EN.pdf └── LM_template.docx
🔄 Convention de nommage
Dossiers candidature : AAAA-MM_Entreprise_Poste/
CV : CV_NomPrenom_[Entreprise]_[AAAA].pdf
Lettre de motivation : LM_[Entreprise]_[Poste].pdf
Rapport RAV : AAAA-MM_preuves_recherche_emploi.pdf
💾 Sauvegarde des données
Les données sont stockées dans le localStorage de votre navigateur — elles persistent tant que vous ouvrez ce fichier dans le même navigateur.

⚠️ Important : faites régulièrement un export JSON (bouton "Export" en haut) et sauvegardez le fichier dans backup_jobs.json. En cas de réinstallation OS ou changement de navigateur, utilisez "Import" pour restaurer.

🔄 Sur la version hébergée avec le serveur sécurisé, connectez votre compte GitHub pour activer la synchronisation automatique. Sur une version locale, la synchronisation manuelle reste disponible (bouton ⚙). Une copie locale de vos données est conservée sur chaque appareil.
